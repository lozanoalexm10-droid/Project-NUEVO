# Mechanical Design

CAD files for the team-designed mechanical platform — chassis, suspension, manipulator, and protective enclosure.

## Contents

- [`stl/`](stl/) — STL exports of every team-designed part, organized by subassembly:
  - [`Chassis/`](stl/Chassis/) — chassis frame, motor mounts, electronics tray
  - [`Suspension/`](stl/Suspension/) — front and rear double-wishbone components
  - [`Manipulator/`](stl/Manipulator/) — arm linkages, gripper mount, turntable
  - [`Enclosure/`](stl/Enclosure/) — drop-test enclosure shell and panels

  GitHub renders STLs inline as interactive 3D models — click any file to rotate it in the browser.

- [`drawings/`](drawings/) — Formal 2D mechanical drawings (PDF), organized by subassembly:
  - [`0.0 Top Assembly/`](drawings/0.0%20Top%20Assembly/)
  - [`3.0 Manipulator-Mobile Interface/`](drawings/3.0%20Manipulator-Mobile%20Interface/)
  - [`3.1 Mobile Robot/`](drawings/3.1%20Mobile%20Robot/)
  - [`3.2 Manipulator Robot/`](drawings/3.2%20Manipulator%20Robot/)

- [`NUEVO baord/`](NUEVO%20baord/) — STEP file for the provided NUEVO PCB assembly, used as a fit/clearance reference during chassis design.

The full SolidWorks part files, library parts, purchased models, and live top assembly live in the team's Box folder and aren't tracked here to keep the repo lean.
